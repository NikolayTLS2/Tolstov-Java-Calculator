
# Java Calculator

## Описание проекта

Консольное приложение-калькулятор,
разработанное на языке программирования Java 21.

Приложение реализует четыре арифметические операции:

- Сложение двух чисел.
- Вычитание второго числа из первого.
- Умножение двух чисел.
- Деление первого числа на второе.

Предусмотрена обработка деления на ноль
с использованием ArithmeticException.

## Используемые технологии

- Java 21
- Maven
- JUnit 5

## Структура проекта

- Calculator.java — реализация арифметических операций.
- Main.java — запуск приложения.
- CalculatorTest.java — автоматические тесты.

## Запуск приложения

1. Установить JDK 21.
2. Открыть проект в IntelliJ IDEA.
3. Запустить класс Main.java.

## Запуск тестов

В терминале выполнить:

```bash
mvn clean test
```

## Тестирование

Реализовано 13 тестовых сценариев,
проверяющих позитивные и негативные случаи
работы калькулятора.
