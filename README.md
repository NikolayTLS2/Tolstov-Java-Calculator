
# Java Calculator

## Описание проекта

Консольное приложение-калькулятор,
разработанное на языке программирования Java 21.

Приложение реализует четыре арифметические операции:

- Сложение двух чисел.
- Вычитание второго числа из первого.
- Умножение двух чисел.
- Деление первого числа на второе.

Предусмотрена обработка деления на ноль
с использованием ArithmeticException.

## Используемые технологии

- Java 21
- Maven
- JUnit 5

## Структура проекта

- Calculator.java — реализация арифметических операций.
- Main.java — запуск приложения.
- CalculatorTest.java — автоматические тесты.
- pom.xml — файл конфигурации сборки Maven.

## Запуск приложения

Способ 1: Через IntelliJ IDEA
1. Установить JDK 21.
2. Открыть проект в IntelliJ IDEA.
3. Запустить класс Main.java.

Способ 2: Через консоль (Maven)
Вы можете собрать исполняемый JAR-файл и запустить его из терминала:
```bash
# Сборка проекта
mvn clean package

# Запуск приложения
java -jar target/calculator-1.0-SNAPSHOT.jar

## Запуск тестов
В терминале (в корневой папке проекта) выполните:

```bash
mvn clean test
```
